# The Corrupted Forest 🌲

Un videojuego RPG táctico isométrico (2.5D) desarrollado en Python utilizando la librería Pygame. 

## Características Técnicas
* **Motor Gráfico Personalizado:** Renderizado isométrico 2.5D construido y gestionado con Pygame.
* **Sistema de Vóxeles y Rotación:** Implementación matemática para la rotación de personajes en 8 direcciones utilizando assets tipo voxel.
* **Inteligencia Artificial (IA):** Lógica automatizada para el comportamiento, movimiento en grilla y toma de decisiones de las unidades enemigas.
* **Interfaz de Usuario (HUD):** Diseño de interfaz con retratos en pixel art, menús tácticos y gestión dinámica de eventos en pantalla.
* **Gestión de Entornos:** Sistema estructurado de tilesets para la construcción modular de escenarios y detección de colisiones.

## Tecnologías Utilizadas
* **Lenguaje:** Python 3.x
* **Librería principal:** Pygame
* **Arquitectura:** Programación Orientada a Objetos (POO)
* **Distribución:** Empaquetado como ejecutable independiente (PyInstaller).
